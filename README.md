
# 🛡️ PhishGuard

## Intelligent Phishing Email Detector

PhishGuard is a Python-based cybersecurity project that analyses email text and detects potentially suspicious content.

### Features
- Suspicious keyword detection
- Risk score calculation
- Email threat classification
- Analysis history using SQLite
- Graphical interface using Tkinter

### Technologies
- Python
- Tkinter
- SQLite

### How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run:

```bash
python3 main.py
```

### Disclaimer

This is an educational, rule-based phishing detector. It cannot guarantee whether an email is safe or malicious.
